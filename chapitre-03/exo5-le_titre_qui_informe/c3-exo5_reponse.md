# Exo 5 — Le titre qui informe

dans cette exercice il etait question que a la fin en haut de lafentre soit affiché:

le nom du document, la taille exacte de la fentre a achaque fois qu'elle est redimensionné et un asterique si le document est modifié.


pour que cela j'ai inserer dans mon code :
```
static void majTitre(nkentseu::NkWindow &window, const std::string &nomDocument, bool modifie) {
    auto taille = window.GetSize();
    std::ostringstream titre;
    titre << nomDocument << (modifie ? "*" : "") << " - " << taille.x << "x" << taille.y;
    window.SetTitle(titre.str().c_str());
}
```
et 
```
 if (event->Is<nkentseu::NkWindowResizeEvent>()) {
                majTitre(window, nomDocument, modifie);
            }

            if (event->Is<nkentseu::NkKeyPressEvent>()) {
                modifie = true;
                majTitre(window, nomDocument, modifie);
            }
```

## teste:
j'ai lancé le programme , le titre affiché etait :
``MonTitre, etape 02 - 794x583``

j'ai cliqué sur la fenetre puis j'ai appuyer sur une touche du clavier , le titre etait:
``MonTitre, etape 02* - 794x583``

j'ai enfin redimensionné la fenetre plusieurs fois et a chaque redimension la fenetre affichait en haut sa nouvelle taille
